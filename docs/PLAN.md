## 1. 研究定位

建议题目：

> AgentGuard: Learning Cost-Sensitive Evidence Acquisition under Adversarial Trust

中文：

> AgentGuard：对抗性信任条件下的成本敏感主动证据获取

研究问题：当公开观测有歧义、历史可信来源可能背叛时，防御智能体如何判断是否值得获取新证据、选择什么调查或干预，并在证据不足时约束高影响行动？

方法包含两个组件：

- **AEP，Active Evidence Policy**：通过公共价值教师监督的 Qwen3.5-4B LoRA 候选策略，学习是否调查、调查对象、工具选择和后续响应；不以新增 VoI head 为成立条件。
- **ECRG，Evidence-Constrained Runtime Governor**：基于公开证据、来源依赖、预算和目标相关性的运行时准入与约束。它不读取隐藏世界，也不替模型按任务编号选择正确试探。

实验命名固定为：`AEP-Policy` 是核心策略监督臂，`AEP-Policy+VoIaux` 是增强臂；`AgentGuard-Train = AEP-Policy`，`AgentGuard-Full = AEP-Policy + ECRG`。增强臂及其 ECRG 组合另行标注，不按最终测试赢家重新定义主方法。旧名 T12、V5-C 可在代码中保留以便追溯。

仓库暂保留 AgentGuard-Zero 名称，论文定名在投稿前查重。已有 [AgentGuard: Runtime Verification of AI Agents](https://arxiv.org/abs/2509.23864)，当前 T12 证据也不支持将“零标注 DCA 参数共进化”当作已完成主贡献。改论文名称不要求现在重命名所有代码路径。

当前实验范围为 **4B、T1/T2、关键因果对照与一个优先外部迁移环境**。T3/T4 专家、三专家路由、9B 全套消融和真实攻击部署不作为本轮主线必需项。已有训练成果保留，不删除，不冒充新协议结果。

## 3. 保留架构，修正信息与监督边界

保持骨干、LoRA rank 和 family/utility 排序结构；公开状态编码需按本节约束去除流程提示。沿用 Evidence/Trust/Memory 的公开状态接口；当前 `probe_value` head 可用于辅助监督，但须验证梯度、优化器参数和损失连接。此次只规划，不宣称已启用。

### 3.1 输入修正与信息对齐

引用保留按一条记录的 `event_id/evidence_id/id` 集合与引用集合求交，不只取第一个 ID。候选实际引用的旧证据必须保留。紧凑表示应包含决策需要的来源依赖、可用时间、验证状态与目标关联；分别记录自报 provenance 与可信链路验证的来源根，不能把换一个 root ID 当成新增独立证据。

动作族选择器不依赖某个候选泄露其答案，但必须能看到公共的独立支持/反驳、冲突、待完成测量和预算摘要。不能只改善候选评分器的输入，却让前置动作族门控仍看不到决定性证据。摘要构造与压缩规则对所有系统一致。

验证多 ID 引用、超过八条证据、根来源变化、时效变化、同一公开世界的编码不变性。保留超长输入显式失败行为；修复后统计 token P50/P95/P99 和超过 2,048 的比例，不靠静默丢证据或筛掉难样本维持旧长度。需要调整长度时重新记录相同条件下的显存与耗时，不能宣称性能必然不变。

### 3.2 信息与物理语义边界

```text
受控隐藏世界与可审计生成机制
             |
             v
公开观测、证据、信任、历史和预算
             |
             v
统一公开候选生成器
             |
             v
AEP: 动作族 + 候选效用
             |
             v
ECRG: 公开证据约束及准入
             |
             v
实际执行调查/干预/响应
             |
             v
新测量结果 -> 证据提交 -> 后续决策
```

同一公开历史下，所有系统使用同一候选生成器、候选预算和可见工具。轨迹分叉后，从各自公开状态重新生成候选，不强求两个不同信息状态的候选参数完全相同。候选生成器本身是方法依赖，需单独审计其覆盖率与隐藏信息访问。

任务 ID、隐藏目标、真实来源控制状态、教师分数、答案性的 `require_*` 流程标志以及可等价推断这些信息的捷径不能进入策略或 ECRG。真实预算、权限和证据前提仍应公开且对所有系统一致；不把合法业务约束全部删除。字段黑名单只能作为初筛，还需检验候选集合、描述、目标顺序、ID 和预算规则是否编码答案。删掉任务名不等于消除任务模板捷径。

行动效果必须由实际目标、控制参数、攻击阶段和环境状态决定，不能因模型自由填写的 `belief` 不同而改变同一个物理控制的效果；意图识别作为独立指标。若动作确实依赖攻击类型，应将这种差异体现为可执行的控制参数。

### 3.3 先做失败分解，再决定架构修改

在已审计的开发状态中记录候选覆盖、动作族选择、族内排序、目标、意图、证据利用、预算与时间耗尽。允许多原因，并区分“首次观察到的错误”与有干预验证的“最早不可恢复错误”；不得凭启发式标签宣称完成因果归因。

若各非空动作集合可在同一公共信念、同一效用和同一后续策略下估值，有：

```math
\begin{aligned}
\max_{\mathcal A}Q-Q(h,\hat a)
={}&\underbrace{\max_{\mathcal A}Q-\max_{\mathcal C}Q}_{\text{候选损失}}\\
&+\underbrace{\max_{\mathcal C}Q-\max_{\mathcal C_{\hat f}}Q}_{\text{族门控损失}}\\
&+\underbrace{\max_{\mathcal C_{\hat f}}Q-Q(h,\hat a)}_{\text{族内排序损失}}.
\end{aligned}
```

这是分解恒等式，不是新定理。若只搜索有限扩展候选，第一项仅是该搜索集上的估计，不声称遍历了全部动作；同时报告 Q 的近似误差。先在开发状态做同 checkpoint 诊断，不直接把旧族内 utility 当成跨族校准后的 Q，也不手工混加未校准的 family logit、risk、VoI。

仅当门控损失确实重要时，再比较跨族校准或以 `max Q within family` 监督族价值；不因数学反例直接取消层级结构。若发现“一次授权处置后禁用全部后续处置”造成高频不可恢复失败，先确定任务是否允许渐进处置，再改为公开执行状态、兼容性与剩余预算约束，重新检查过度响应。新增动态信任模型也先作为轻量基线，不立即加进主架构。

## 4. 四种接口的准确分工

T1/T2 使用同一套接口，区别在于不确定性的来源，而不是指定不同的正确工具。

| 接口及兼容名 | 类型 | 真实可执行的操作 | 公开返回 | 不能据此推出 |
|---|---|---|---|---|
| AttestationChallenge / SourceChallenge | 主动来源验证 | 发出 nonce，请求可核验记录、签名及时间信息 | 挑战回执、签名验证、记录匹配、延迟和证明依赖 | 签名有效不等于声明真实 |
| SensorCanaryProbe / CanaryProbe | 环境干预式试探 | 向授权遥测路径注入无害唯一标记 | 哪些传感器看到标记、到达时间、内容是否保持 | 标记丢失不等于来源恶意 |
| DecoyInteractionProbe / DecoyProbe | 环境干预式试探 | 在无生产权限的隔离区域部署诱饵 | 时间、连接、访问实体及交互序列 | 无交互不等于无攻击 |
| ShadowEnforcementProbe / ShadowActionProbe | 响应影响评估 | 在镜像/历史流量上执行规则 dry-run | 会话匹配、流量量、公开服务依赖和估计影响 | 不能直接得知真实攻击覆盖或真实良性会话标签 |

**Canary 和 Decoy 是环境干预的重点；不把来源认证、SQL 检索和 shadow dry-run 都包装成攻击者行为干预。** 四个接口均保留，没有为了突出一种工具而禁止其他合法调查方式。

首轮只要求一个干预机制完整、可审计地支撑论文主张，优先 SensorCanaryProbe；Decoy 的全面扩展不作为前置条件。所保留接口的实际语义和实现成熟度必须逐项标注；简化接口不宣称通过与完整机制相同的因果验证，也不根据最终测试成绩挑选重点工具。

### 4.1 因果环境约束

实现 `操作 -> 环境交互 -> 传感器测量 -> 公开观测`。不能实现成 `Probe 名称 -> 隐藏真假 -> 换一种字段返回答案`。

每种测量明确覆盖范围、延迟、正常噪声、超时、攻击者控制能力，以及检测器/估计器的数据来源。Canary 应有良性丢包；Decoy 应有良性背景交互和诱饵规避；T2 应包含合法密钥仍有效的来源接管。不得用测试集结果反向调整这些参数。

若返回 `estimated_attack_coverage` 等估计，只能来自已声明的公开数据估计器，并公开误差假设；直接基于隐藏标签计算的真实覆盖留在离线评价侧。新 root ID 不自动代表独立证据，需记录共同采集器、管理域和可被同一攻击者控制的依赖关系。

### 4.2 生命周期与成本

```text
proposed -> admitted -> pending -> resolved/expired -> evidence_committed
```

动作不能引用尚未返回、尚未提交的结果。同一步提交的响应不应使用该步未来才得到的测量。成本、延迟、超时以及失败尝试是否收费写入协议。建议尝试即收费，并单列 Invalid Tool Cost。

在有噪声条件下，有价值的重复测量可能合理。ECRG 只拒绝明确重复且无新信息、参数非法或超预算的操作，不能把所有重复试探一律屏蔽。

## 5. T1/T2 场景与控制组

### T1：当前证据歧义

probe-beneficial 组共享同样的试探前公开历史，但隐藏世界要求不同的安全决策。必须检验完整可用历史，而非仅比较初始一帧。

例：可疑活动可能位于两个区域，当前来源不能可靠定位；两处响应的业务后果不同。策略需要选择可区分相关活动的测量位置，再依据结果行动。不是用题目名称告知“此题必须 Decoy”。

### T2：来源信誉与当前声明分离

配对世界具有共同 honest prefix，随后出现同样的关键声明。一侧可能是来源接管，另一侧是正常来源面对真实攻击或合法变化。历史信誉本身不能暴露分叉。

必须包含签名仍有效的背叛、良性遥测故障、真正需要及时响应的合法声明，以及已存在充分独立证据而无需再试探的情况。

### 共同控制组

- 已有公开证据充分，直接或可逆响应更优。
- 被动验证足够，无需环境干预。
- 试探能够减少与决策无关的不确定性，但净效用不高。
- 测量结果分布几乎相同，试探无信息。
- 试探代价或等待时间过高，继续试探不划算。
- 试探证实原判断，最优动作不改变。

控制组与挑战组按事先声明的生成机制构造。训练可以增加有用机会的覆盖；最终测试不能根据模型是否成功或 probe 是否得到好结果再筛选。

## 6. 公开信息约束的教师

教师可以离线使用已知仿真模型和隐藏世界集合计算监督，但不能在当前动作中使用只有教师知道的真实世界身份。

强制约束：**相同公开历史对应相同的决策分布；噪声观测不能区分的后续分支也必须共享策略。** 隐藏真值 Oracle 与公共信息 Reference 分开实现、分开报告。

### 6.1 首版教师：有限状态、正确后验、有界搜索

在受控场景中明确任务状态、来源可靠性、正常故障及其转移/观测似然；优先有限状态枚举或经过验证的小型加权信念表示，不开发通用大型 POMDP 求解器。T2 至少区分“世界真的变化”与“来源失效”；模型和基线不得获得当前隐藏身份。

```math
\bar b_{h,a}(s')=\sum_s P(s'\mid s,a)b_h(s),\qquad
b_{h,a,y}(s')\propto P(y\mid s',a,h)\bar b_{h,a}(s').
```

不能对每个世界只采样一次，再根据 observation digest 把不同噪声结果当成世界已被识别。digest 可用于缓存，不能替代观测似然。无信息硬币与隐藏世界独立时，后验必须仍为原先验；“两个单样本恰好不同”不产生信息。独立样本估值或共同随机数不能自动修复错误后验。相关粒子退化背景见 [POMCPOW](https://arxiv.org/abs/1709.06196)。

合法调用的超时、丢包和失败是需要付费的随机结果，进入期望价值；不能模拟后看到失败就事先移除候选。只有从当前公开前态可确定非法的动作才可提前排除。

首版使用记录预算的有限时域/beam 搜索；搜索须覆盖待完成测量及至少一次后续处置，不能将 `H=3` 写成完整多步最优。对无信息、部分可靠、互补两次测量、同根重复证据、合法变化和来源背叛的小环境，用精确枚举验证后验与价值。无信息且无物理效果的查询，在静态无等待收益案例中，净收益应为负调用成本。

### 6.2 决策价值与流程标签脱钩

令 `h` 为公开历史，`b_h(s)` 为该历史下的信念。用有限时域的公共策略计算：

```math
Q(h,a)=\mathbb E_{s\sim b_h,\,s',y\mid s,a}
 [r(s,a,s')+V(h\oplus(a,y))],\qquad
V(h)=\max_{a\in\mathcal A(h)}Q(h,a).
```

```math
\operatorname{Adv}_{probe}(h,p)=Q(h,p)
 -\max_{a\in\mathcal A_{nonprobe}(h)}Q(h,a).
```

所有业务损失、试探成本、验证成本和延迟在统一效用中只计一次。上述比较的是先试探与先不试探，后续均可依法继续行动；“全程不允许试探”属于另一种策略限制，另行评价。若仅做有限深度搜索或采样估计，记录近似算法、随机性、搜索预算和误差检查，不宣称精确最优 VoI。

教师主标签改为同一公共信念下的候选价值最优/可接受集合，而非先指定 lifecycle family 再族内最大化。同步处理环境要求、候选过滤、标签覆盖、状态采样和评价，不能只从输入删字段。旧数据可计算 `max Q_core - Q_core(lifecycle_target)` 作为监督冲突诊断；若旧 Q 仍含流程奖励，该差值不是新协议的真实 VoI。

### 6.3 如何鼓励主动试探

主动生成足够多具有正净收益的调查机会，监督正确工具和目标，并保留试探前后完整链。不要因为自然采样很少出现 probe 标签就放弃训练它，也不要把无价值状态强行标成 probe。

当公开信息下的净优势可靠为正时，教师偏好有用试探；优势不确定或近似误差较大时，使用软标签/低权重，不把估计噪声作为确定答案。确认原判断、恰当的不试探和及时响应均是正确行为。

训练状态应覆盖决策边界、来源变化、信息互补和不同成本，而非只补高熵或更多 probe 样本。若能给出覆盖偏差的统一 Q 误差界 epsilon，可用超过 2 epsilon 的优势筛选强标签；只有 Monte Carlo 标准误时，不能冒称已得到该保证。

### 6.4 两条匹配训练臂

首轮先修正候选价值与动作族标签，再比较：

```math
\mathcal L_{M0}=\mathcal L_{public\text{-}value\ policy},\qquad
\mathcal L_{M1}=\mathcal L_{M0}+\lambda_{voi}\mathcal L_{voi\text{-}aux}.
```

M0 与 M1 使用同一教师动作标签、初始化、候选状态和训练/选择预算。M0 的动作标签本身已编码信息价值，模型是否学到仍需实测；该消融检验的是**显式 VoI 辅助监督的增量价值**，不是“有无信息价值思想”。主表报告两臂，无增益也如实保留，不因辅助头无效宣布整个学习方法失败。

正确 probe 类型、目标及 follow-up 通过候选排序和完整链样本教学，不同时叠加七个奖励。信息增益、直接引用率和改主意次数作为诊断，不作为无条件奖励。每个被声称训练的 head 都要验收梯度、优化器归属、损失开关、保存与独立重载。

在确有开发集分布偏移时，最多先做一轮 train-only on-policy 状态补充，并重新冻结数据清单。主方法与匹配对照共享状态采样；若样本量改变，明确更新双方预算。现有 `probe_value` 首先只作训练辅助，不自动加到部署分数中。

## 7. ECRG 的角色

ECRG 与环境共用公开授权谓词，校验动作目标、引用证据可用性、来源依赖、响应兼容性及剩余预算。不得用隐藏标签或教师价值选择动作。

首轮采用明确的准入规则，再在可行动作中保留 AEP 排序；复杂启发式重排单列为后续消融。若没有合法高影响响应，可选择已存在于公开动作空间的调查、可逆动作或 Observe，不允许凭空强制插入“正确 Probe”。

阈值拟合限于训练/专用校准组，开发集定型，最终测试不调参。对同一策略分别评价 ECRG 开与关；还要评价简单规则策略加 ECRG，以分离“策略学到的收益”和“治理规则的收益”。

共享谓词的一致性可做属性测试，但不能把公开约束满足等同于隐藏世界绝对安全。有限测试零违规是经验观察，不自动构成形式保证。

ECRG 的主要假设是在合理保持处置能力时降低实际误处置、错误证据授权与无效操作，尤其在来源污染和机制变化时改善风险—收益。不要求同时提高每一项指标。若只修复旧 T2 的 6 条过度响应且其他状态完全不变，Safe Success 增长上界仅为 4 个百分点；这不是 ECRG 改变完整轨迹时的总体能力上限。

先审计 ECRG 与候选预过滤、环境最终授权的功能重叠。如果候选已全部满足相同谓词，ECRG 可能没有额外空间，应如实报告；不能为制造治理增益而给对照关闭环境必要安全检查。

## 8. 数据协议与训练预算

下表是首轮建议规模，**不是已经生成或完成的数量**。修改规模或预算必须在最终测试前登记，不能静默降级。

| 数据层 | 建议规模 | 用途与隔离 |
|---|---:|---|
| 新 train | 4,000 个候选状态记录，T1/T2 各 2,000 | 新教师监督；记录 episode/group/机制 lineage |
| 新 offline dev | 400 个候选状态记录 | 监督与解析检查，不当作完整轨迹结果 |
| 新 rollout dev | 400 条隐藏世界轨迹，T1/T2 各 200 | checkpoint 与部署参数定型；与 train 和 offline dev 按 group 隔离 |
| 新最终测试 | 1,200 条隐藏世界轨迹，T1/T2 各 600 | 每任务 300 个配对 group；600 条标准分布、600 条机制外测试，总数不是相加为 2,400 |

训练集可以提高正 VoI 状态覆盖，但不强制四种工具标签各 25%，也不强制所有任务拥有相同最优工具比例。最终测试的机制分布、噪声和成本区间预先登记，不按教师赢家或模型成绩筛选。

旧 400-record dev、400-trajectory epoch-dev 和 fair_s1/s2/s3 不再充当新最终测试。分割以生成机制、公共同源 group 和语义结构为单位，不能只换 ID 或随机种子。最终测试至少留出来源接管方式、共同证据根、延迟/噪声及成本机制的组合。

首轮沿用 4B、LoRA rank 16、global batch 16 和至多 4 epochs 作为比较起点；4,000 条每 epoch 对应 250 steps，至多 1,000 steps。所有可比训练臂从同一经审计 D0 初始化，完整披露 D0 已受过的监督，而不是称为纯原始 base。不要使用已看过保留结果的旧 T12 checkpoint 当新主方法唯一初始化。

先完成 M0/M1 的一对稳定运行，再争取两臂各三个配对训练 seed；扩展前固定 seed 清单，同一对共享训练数据与评测组。若实际仅完成一个训练 seed，则明确限制，不把三个评测 seed、四个 epoch 或两个隐藏世界冒充独立训练重复。无论完成几次，均报告全部运行，不只报告最好的一个。

候选长度、batch、horizon 和历史压缩在短门禁后记录到新 manifest；不能沿用未验证的耗时估计。horizon 必须容纳 T2 共同前缀、分叉、测量返回与响应，不能静默丢弃后续事件来加速。只保存有用途的阶段/epoch 边界，不逐步保存大 checkpoint。

### 8.1 Checkpoint 选择与保留 T2

先将固定的历史 T12 checkpoint 通过相同新公共接口，在修订协议 rollout-dev 上做冻结迁移评价，作为 T2 保留参考；共同 D0 单独报告为初始化参考。两臂共同最大化 T1/T2 macro Safe Success，同时满足预登记的 T2 非退化容忍量 delta 与业务风险/成本上限；不能把旧协议 66.67% 直接当新协议阈值。

delta、风险上限、并列时的成本/步数规则必须在训练比较前记录，不能看最终测试再定。旧 T12 参考不充当主方法独有的训练初始化；若新接口不兼容或旧参考失去可比性，必须说明，不能偷偷换成更弱的参考再声称保住旧能力。若没有 checkpoint 满足约束，应报告不通过而非放宽约束。开发集不应因反复试验而扩成隐形测试集，记录尝试次数和预先限定的配置搜索预算。

### 8.2 数据与产物清单

每批记录协议版本、代码哈希、生成机制/参数、group 与 episode、公开状态/候选摘要、教师版本/搜索预算、主标签和辅助标签。模型记录初始化、累计监督、训练数据哈希、seed、epoch、选择规则及 ECRG 状态。正式测试另行生成并封存，不能重用历史 retention，也不能按模型成绩或教师赢家过滤。

## 9. 主实验与消融

### 9.1 主表

| 系统 | 参数训练 | 主要回答的问题 |
|---|---|---|
| 公开规则：证据不足先验证/调查 | 无 | 简单规则是否足够 |
| 公开规则 + ECRG | 无 | 治理规则本身贡献多少 |
| 轻量公开特征排序器 | 相同 train 状态 | 收益是否需要语言骨干 |
| Qwen3.5-4B Zero-shot candidate choice | 无 | 仅骨干、提示和同候选接口是否足够 |
| Qwen3.5-4B ReAct + same tools | 无 | 普通多步推理与工具调用能做到多少 |
| 成本敏感短视策略 | 无 LLM 梯度；估计器仅在允许的 train 数据拟合 | 多步学习是否超越简单价值启发式 |
| AgentGuard-Train / AEP-Policy / M0 | 公共价值教师的策略监督 | 学习的证据与处置策略是否有效 |
| AEP-Policy+VoIaux / M1 | 同 M0 + 显式 VoI 辅助监督 | 辅助监督的额外价值 |
| AgentGuard-Full | 同一 M0 checkpoint + ECRG | 治理额外收益与代价 |
| Public-information Reference | 无梯度训练 | 公开信息可达到的参考性能 |
| Hidden-state Oracle / Random | 无梯度训练 | 全知与随机参考；近似搜索不冒称严格最优上下界 |

Zero-shot 采用同 backbone 的生成式候选 ID 选择，不把随机初始化的分类 head 冒充 zero-shot。ReAct 也接同一公开动作空间。每个相同公开状态中的候选、工具访问和外部信息一致；记录候选数、模型前向量、tokens、实际查询数及时间，不只匹配“动作步数”。

轻量模型使用与 AEP 同样允许的公开信息和监督，不偷用任务编号、隐藏来源状态或教师在线分数。成本敏感短视策略使用可公开声明或从训练估计的概率，不读取实际隐藏先验/状态；精确模型版与估计模型版要区分。可借鉴 [Calibrate-Then-Act](https://arxiv.org/abs/2602.16699)，但未忠实复现时标为 CTA-inspired，不冒用原论文成绩。

工具权限、可见信息、环境预算必须共同；token 数和计算结构不必强行相等，但必须报告并做合理预算对照。不得通过后处理替基线移除自主拒绝、等待或调查。先接通规则、短视、轻量模型和同骨干推理基线，再投入大规模新训练；不要求复现每篇相关论文。

Historical V9 和旧 T12 作为历史对照另列，不能代替同数据训练消融。Memory Agent、Trust-score Agent 与可接入的 Cyber LLM 可作为补充；不为填满表格而挤占核心因果与公平对照。未部署或未跑完的系统明确留空。

### 9.2 优先消融

1. **w/o explicit VoI auxiliary loss**：M0 对 M1，同初始化、同训练状态、同预算；不解释成“没有信息价值思想”。
2. **ECRG 开/关**：同 checkpoint，不重新训练；加入规则策略 + ECRG。
3. **不允许环境干预式 probe**：保留被动验证/来源挑战，公开标注为推理期能力移除；不冒充重新训练的消融。
4. **结果屏蔽与无试探 rollout**：分别估计信息利用与整体干预效果。
5. **无信息/高成本 controls 与机制外测试**：检验选择性和泛化。

四工具逐个移除、on-policy 数据补充消融以及更多骨干放在后续优先级。推理期屏蔽与从头训练禁用某机制回答不同问题，必须明确标签。

机制外测试首轮聚焦三类：历史可信来源当前失效、证据共享上游、正常噪声或延迟；同时覆盖合法变化与不同调查成本。预登记少量机制及组合，不展开所有来源/拓扑/工具/预算的笛卡尔积。它们从第 8 节的 1,200 条最终轨迹中划分，不额外重复计算样本量。

## 10. 指标与因果评价

### 10.1 主指标

主表报告任务成功、安全效用、攻击缓解、过度响应、业务损失和调查成本，并画出预算与安全效用/成功率的关系。拒绝所有响应可能降低风险，却不能在攻击任务上获得高成功率。

旧结果使用 `correct_intent AND attack_mitigated AND NOT overresponse AND false_promoted_count == 0`。若新协议包含真正无攻击的合法变化控制，不能要求它们也“缓解攻击”。新协议应明确：

```text
TaskSuccess:
  attack world -> correct task-specific mitigation objective achieved
  benign/control world -> correct safe handling and required service preserved

SafeSuccess_vNext = TaskSuccess AND no_defined_unsafe_response
                   AND no_false_confirmed_memory_promotion
```

各目标和阈值须在数据冻结前定义。意图识别单独报告，在没有对应类别的控制场景中标 N/A，不强迫现有四分类头回答不存在的第五类。**新旧指标不能直接跨协议比较；全部基线在新协议重跑。**

### 10.2 试探诊断

报告选择正净收益试探的 precision/recall、目标与类型正确性、不必要试探率、重复/非法操作、结果送达率和 probe 后决策质量。VoI 标签由公共信息 Reference 估计并标注近似性，不称为任意真实部署中的可得真值。

Probe-grounded revision、直接证据引用和调用频率只作诊断。确认原判断同样可能有价值，不要求所有有效试探必须换动作。

### 10.3 三种干预分别计算

| 实验 | 固定什么 | 改变什么 | 解释 |
|---|---|---|---|
| Hide result | 试探已执行，世界影响和成本/时延保持 | 在结果送达前屏蔽其信息及派生状态 | 该结果信息对策略的作用 |
| No probe | 相同初始世界与可对齐外生过程 | 改为非 probe 首步，并自然重新 rollout | 整个试探的净效用 |
| Corrupted result | 明确的生成机制与攻击预算 | 可实现的结果污染 | 证据错误下的鲁棒性 |

不能把三种差值合成一个“因果收益”。无试探分支不能沿用干预后的隐藏状态；屏蔽分支不能从 trust/memory 或候选参数看到已隐藏结果。外生噪声按事件/过程键固定，而非只用一个会随调用次数移动的随机数流。

在同一预定状态集合与配对方案下，可以分别定义：

```math
\Delta_{info}=\mathbb E[U_{show}-U_{hide}],\qquad
\Delta_{intervention+cost}=\mathbb E[U_{hide}-U_{no\ probe}].
```

两项之和是该比较下的总效应；第二项包含物理影响、调用成本、时延与后续决策，不能称为纯物理干预收益。Corrupted result 是另一种鲁棒性实验，不混入此加法分解。预先规定非 probe 首步如何选择，以及各分支后续是否可继续 probe；不要混淆“这一步不 probe”与“全程禁用 probe”。

采用预先指定的可试探状态集合做总体比较；另报告实际选择试探的子集，避免只挑有正收益的轨迹。按 public group 聚类做配对区间/置换检验，报告不同训练 seed 与评测 seed 的区别。若只完成一个训练 seed，明确证据限制，不把多个配对世界或多次评测冒充独立训练重复。

最终 1,200 条轨迹共 600 个配对 group；T1/T2 各 300 个 group，若各自 ID/OOD 对半，则每任务每分布只有 150 个 group。每张表单独列分母，不用总量代替子组有效样本量。多 seed 时报告逐 seed 差异及组内配对区间，预登记主要比较与多重比较处理。零错误仅是有限样本结果，不写成零风险。

Betrayal 检测须区分“提出怀疑”与“证实失信”，绑定正确来源、背叛后的时间窗口和证据；同时报告正常变化的误报、错误拒绝及首次有效检测延迟。不能把 challenge 所有声明当成成功检测，也不能仅靠旧 `false_distrust_rate` 判断没有误报。

## 11. 场景可靠性的四层证据

### 11.1 网络安全来源映射

为每个机制记录公开技术来源、遥测类型、实体和响应语义、适用前提与简化假设。例如遥测受损需能映射到公开防御规避/日志机制，诱饵响应需有明确行为假设。维护版本化来源映射表，可参考 [MITRE ATT&CK](https://attack.mitre.org/)。映射不等于真实生产分布认证，不虚构专家评分。

### 11.2 程序化有效性

校验 schema、状态转换、动作目标、预算、证据生命周期和数据隔离。公开候选不得读取隐藏状态。对观测等价的世界检查公开历史和候选一致性。加入属性测试：相同公开前态下 ECRG 与环境的同一授权谓词结论一致。

### 11.3 行为可解性

分别运行隐藏真值 Oracle、公共信息 Reference 和定义明确的 Random。仅在 probe-beneficial 子集要求正信息优势与足够后续预算，控制子集要求存在更优非 probe 策略。

噪声、超时和有限预算可能使公共 Reference 的成功率达不到 100%，不得删除这些失败来满足不合理门槛。随机策略低于某个百分比也不是真实性证据，必须冻结其动作族/目标采样方式。

### 11.4 外部验证

外部环境提供独立任务与数据证据，但不会自动证明全部合成场景真实。它验证什么，论文就只声称什么。

## 12. 外部迁移的现实路线

优先 **ExCyTIn-Bench**，用于威胁调查与主动证据获取迁移；ToolSandbox 作为资源允许时的非网安工具环境补充。不要同时把原生 CAGE、多种日志环境和 CALDERA 全部设为本轮必须完成。

当前 ranker 不直接生成 SQL。适配必须显式拆分：

```text
外部问题与公开 schema
 -> 固定、各系统共享的查询/答案候选提出器
 -> 公开结果与证据表示
 -> 基线或 AEP 候选选择，必要时 ECRG 准入
 -> 数据库只读执行，结果返回
 -> 最终回答与官方/声明的评分器
```

固定候选提出器、查询预算、答案生成器、judge 版本和工具权限，并检查正确候选是否根本未被提出。若为外部任务重新训练或调参，只能称为适配后的迁移，不是零样本迁移。AEP 只选候选，不把提出器的知识收益全部归给 AEP。

ExCyTIn 原仓库公开结果使用 `max_step=25` 和 GPT-4o 评价，并于 2026-08-26 推荐新的评测框架。应先冻结所用 commit、问题版本与评分方式；40 题仅作为试运行，若采用自定义子集或 15 查询协议，必须同协议重跑基线，不能直接拼接官方榜单数值。[官方仓库](https://github.com/microsoft/SecRL)

外部试运行先用至多 40 题检查只读执行、候选覆盖、问题/答案映射、评分一致性、耗时及费用。其余题目在接口定型前不用于调参，正式范围按事件/问题组提前划定，试运行题不计正式成绩。对比至少包含相同候选提出器下的同骨干推理选择、M0、M0 + ECRG；计算轻量时补规则/短视选择，不只跑我们自己。官方最终分数与自定义过程/证据指标分开；没有可靠标注就不虚构 Evidence Recall。

外部新动作族与文本编码必须有显式、无答案信息的接口映射；仅“把 SQL 叫 GraphQuery”不等于解决分布差异。映射失败或需要任务监督时，转为如实标注的适配实验，不宣称零样本迁移。外部接口研发设独立停止条件，不能阻塞内部有效性修正。

正式规模由一次有界试运行决定并预登记，优先覆盖多个独立事件而非仅增加同一事件的相似问题。按事件聚类报告不确定性。SQL 获取已有日志证明调查能力，不证明 Canary/Decoy 的攻击者行为干预，更不证明生产环境隔离与恢复。

## 13. 方法实施门禁

以下均为待执行的功能门禁；已有 CPU 发布测试通过不代表它们已完成。

| 门禁 | 必须验证的内容 | 不通过时 |
|---|---|---|
| G1 输入与合法性 | 多 ID 旧证据保留；根来源和时间表示；family/candidate 信息对齐；无答案性流程提示；必要公开约束保留 | 修输入/协议，不开始新训练 |
| G2 教师 | 无信息、噪声、互补测量、重复同根、合法变化、背叛六类精确小例；失败调用不被预知；无流程主标签覆盖 | 修后验/标签，不靠增加模型补救 |
| G3 环境与评价 | 同物理动作不受自由 belief 标签改变；正确目标授权；背叛证据/时窗与误报；无 probe 和 hide-result 状态分叉；成本只计一次 | 修所有比较共享的环境/评分 |
| G4 参考与失败诊断 | Public Reference、规则及短视策略的可解性、控制组行为；候选/门控/排序损失和后续处置限制诊断 | 报告不可识别或不可解状态，不按赢家筛测试 |
| G5 参数训练 | 一个完整梯度与保存/重载检查；两臂最长 episode 小规模端到端测试；未缺终局分数、未截断未来事件 | 修工程故障，不提交整套任务 |
| G6 冻结与评测 | 数据/代码/教师/选择规则哈希、共享 seed 与预算；ECRG 条件明确；正式测试不可用于调参 | 不生成正式论文表 |

每个门禁只做足以覆盖风险的有界验证，功能变更触发受影响测试，不无限堆叠新性能 pilot。记录教师搜索、数据处理、token 分布、训练、评测、I/O 的实测时间，再估算工期；不承诺未实测的 12/24/30 小时。

G6 前必须填完的协议项包括：成本/损失系数、观测噪声与来源转移、公共可见条件、horizon、训练与候选预算、delta/风险上限、最终组分布、主比较与统计方法、seed、有限参数搜索次数及外部评分版本。未定项不能在测试结果出来后补填。

先用公共 Reference 和简单规则确认任务存在可学习的信息收益，再开始主方法训练。若 Reference 自身不能稳定估计优势，不用更多 GPU 训练掩盖问题；修复协议后重新冻结。

## 15. 创新边界与最终标准

主动获取信息、信息价值和运行时安全约束已有研究，不能不加限定地声称“首个主动试探智能体”或“首个安全 governor”。相关一手资料包括 [VoI for Human-Agent Communication](https://arxiv.org/abs/2601.06407)、[ShieldAgent](https://arxiv.org/abs/2503.22738)、[LLM Cyber Defenders](https://arxiv.org/abs/2505.04843) 和 [ToolSandbox](https://arxiv.org/abs/2408.04682)。

新增重点对照为 [Calibrate-Then-Act](https://arxiv.org/abs/2602.16699)：何时付费查询本身不是新问题。公共信念教师需要对照 [POMCPOW](https://arxiv.org/abs/1709.06196) 等工作的后验退化问题，但小型受控环境的正确枚举不等于必须引入完整通用求解器。

值得验证的新增价值是：在来源可能背叛的条件下，通过公共信息约束的教师学习成本敏感的证据获取，再由证据相关治理约束高影响动作；在公平基线、配对因果对照、机制外变化和独立调查环境中证明边界清晰的收益。

最终不以 probe 调用次数、人工挑选的高分或固定的结果排序验收。应当看到：何时试探的判断更好、正确利用或确认信息、无价值试探更少、总体任务与安全成本的权衡改善，并如实披露失败和尚未成立的主张。

**研究不依赖所有增强同时成功。** M1 无增益时保留 M0 并报告负结果；ECRG 只改善风险时按风险—收益写，不强求大幅成功率增长；轻量模型持平时不宣称 LLM 必要；因果证据未成立时不把流程执行包装成主动信息学习。已有 T12 是需要保护与检验的基础，不是需要被新模块全部取代的失败版本。
