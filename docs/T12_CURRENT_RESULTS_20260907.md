## 2. 三组保留套件结果

原始 `fair_s1/fair_s2/fair_s3` 每组含 T1–T4 共 200 条隐藏世界轨迹。**本页只报告每组 T1 50 条、T2 50 条，即每个系统合计 300 条 T1/T2 轨迹，不是 600 条。** 每个任务每组为 25 个配对 public groups，两个世界不能视为独立样本。

这些套件已经被检查并用于后续研究设计，统一列为 **development/retention evidence**。名称中的 `fair` 或原始目录中的 `final` 不代表它们仍是新版未接触的最终测试集。

## 3. 不能省略的负面结果

### 3.1 原始保留门禁没有通过

原始 `retention_gate.json` 的 `accepted=false`。其失败列表包含：

- `pooled_overresponse_not_higher`；
- 三组 T2 的 `intent_accuracy_within_one_trajectory`；
- 三组 T2 的 `overresponse_not_higher`；
- fair_s3 T1 的 `overresponse_not_higher`。

原门禁的 pooled 项含四个任务，而任务特定项包含 T1/T2 的实际退化。本页不覆盖原门禁结论，也不以更高 Safe Success 将失败改写为通过。

### 3.2 主动试探行为仍有限

这些是合并轨迹文件中的策略决策记录，不是按两个隐藏世界各复制一次的执行次数。T1/T2 中均未观察到 DecoyProbe 或 ShadowActionProbe 被选中。不能把该结果当成已经掌握四类独立试探。

旧版 Probe Yield 的轨迹均值为 T1 44.00%、T2 18.67%；旧 `probe_grounded_action_revisions` 总和均为 0。旧 T2 betrayal detection 均值仅约 0.67%，各组为 2%、0%、0%。这些值保留在 JSON 的 `legacy_*` 字段中，只作诊断，不解释为新方案的因果净收益或可靠的背叛识别结论。

直接证据引用规则较窄，值为 0 不能单独证明模型完全没利用结果；同样，Probe Yield 非零也不能代替干预对照证明因果收益。

## 4. Safe Success 与统计边界

逐条终局核对的旧版 Safe Success 定义为：

```text
correct_intent
AND attack_mitigated
AND NOT overresponse
AND false_promoted_count == 0
```

这是当前协议的合取指标，不是跨 benchmark 通用分数，也不是对真实生产系统的安全保证。不能把它与不同任务、预算、工具和成功定义的公开榜单直接比较。

本页不提供将 150 条配对世界误作 150 个独立样本的置信区间。正式推断应按 public group 聚类，训练随机性另行报告。本次没有重新运行聚类统计或多 seed 训练。

## 5. 这批结果能支持什么

可以支持：在已有协议的保留套件上，T12 专项训练后的策略比历史 V9 获得更高 T1/T2 缓解和安全成功，且确实选择过部分主动试探动作。

不能支持：新版机制无泄漏、四工具泛化、正因果试探收益、ECRG 额外收益、参数共进化成功、超过强同预算基线、外部调查迁移或真实防御部署。这些均在新规划中列为待验证。
