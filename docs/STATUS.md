### 1.1 本轮环境与指标修复

环境修订为 `aep-env-20260908-v1`，指标修订为 `aep-metrics-20260908-v1`；它们独立于旧 TMCD JSON schema 版本，尚不是新正式实验协议的冻结声明。

| 部分 | 已实现的语义 |
|---|---|
| 物理响应 | 缓解效果保留目标匹配、动作强度和攻击阶段约束，不再乘以模型声明的意图是否正确。意图识别单独报告。 |
| 正常对照 | 通过内部 `true_attack.present=false` 显式声明；不会产生虚构攻击进展或攻击失败。`legitimate_change` 不自动等于无攻击。 |
| 轨迹终止 | 已缓解但仍有后续事件或 pending probe 时继续；评测与教师续推使用环境终止状态。结束后不能继续动作来修补终局得分，旧 post-terminal audit 开关拒绝启动。 |
| 背叛检测 | 普通 challenge 只算怀疑；确认检测要求已提交的、来源正确且有相关负向证据支持的信誉更新，证据在该时刻可用，且绑定背叛事件。正常变化的误怀疑和错误拒绝分别报告。 |
| Canary | 从即时真假判词改为仿真标记注入、pending 回执、延迟遥测及超时。回执不是证据；返回标记是否到达/完整等测量，不直接输出声明真假或攻击标签。 |
| 试探计分 | 删除无条件 Probe Yield 奖励及旧教师附加流程奖励；后续引用只是诊断，不自动等于因果收益。新公共价值教师仍待实现。 |
| 成本与汇总 | 失败的实际工具尝试收费一次；预算拒绝不再收费。报告 Invalid Tool Cost 与有效验证成本，合并分片按适用总体加权，拒绝混合指标版本。 |

新 Task Success：有攻击时要求完整轨迹成功缓解；无攻击时要求完成观察时域、没有错误限制业务且业务成本不超预算。Safe Success 在 Task Success 上进一步要求无过度响应和错误记忆确认。意图识别不再作为该成功指标的隐藏门槛。

攻击缓解与意图识别只统计有攻击场景；确认背叛检测以场景时域内预先规定的背叛 episode 为分母，策略提前失败不能把未检测的背叛排除。不存在适用总体时，汇总输出 `null` / 不适用，而不是 0 分。单轨迹中的兼容数值必须结合 `*_applicable` 或计数字段解读。

兼容字段 `probe_yield` 表示证据使用率；`probe_grounded_action_revisions` 当前表示试探证据参与响应授权，不证明动作相对无试探发生改变。输出明确标记 `probe_yield_is_causal=false`，另提供 `probe_grounded_authorizations`。正式论文的净信息价值仍须固定随机环境、对有信息/隐藏信息/无试探轨迹进行独立验证。

Canary 默认通道的丢包、损坏和延迟不因来源身份自动变化，因此默认可以是无信息试探；通过显式 `probe_model.canary.mode_overrides` 才能设定受控通道差异。参数、噪声键和攻击存在标签仅供内部仿真，不公开给策略。它是可测试的仿真干预模型，不是已部署的真实网络工具，也不是经真实日志校准的传感器模型。SourceChallenge、Decoy 和 Shadow 的旧抽象机制尚未整体升级。

本轮增加确定性反例测试，并保留全部原有测试与历史结果哈希检查。服务器完成 130 项 CPU 测试、8 个 T1/T2 场景 smoke 及发布完整性检查。CPU 检查不证明 GPU 稳定性、训练速度或性能提升；详细运行记录留在服务器私有 `workspace/reports/`。新旧环境、奖励和指标已经不同，旧 T12 数字不得直接换算或贴上新版本标签。

### 2.1 最新本地源码与 CPU 反例核验

以下单独核验固定在公开源码 `1a4d45e9fd7e165331ef3f5c1e42e0c7cfd6d075`，直接调用当前编码函数；不是新增服务器模型推理。

| 检查 | 结论与证据级别 |
|---|---|
| 九条 evidence，同时有 event ID 和 evidence ID，候选引用最旧的 V0 | 实际 `_compact_public_state` 只保留 V1-V8，V0 丢失；确定性最小反例 |

| 最小输入只改变 `available_at` | 实际 `public_state_text` 相同；紧凑文本遗漏该时间差异 |
| `_apply_lifecycle_supervision` | 源码确认主标签先指定流程动作族，再族内选 Teacher-Q；其他 teacher 辅助信息仍有保留 |
| 历史中已有 authorized mitigation | 源码确认候选合法性会禁止后续缓解，不检查是否已充分缓解 |
| 动作族硬门控 | 源码确认先选族再族内排序；尚无历史 regret 归因统计 |

前三项证明条件成立时存在信息丢失，不证明它们出现于多少历史轨迹；来源信息也可能通过其他公开状态间接体现。上述问题尚未修复。增加输入信息可能影响 token 长度，必须重新检查长度上限和显存，不能声称开销必然为零。

另独立复算了老师的数学例子：在两世界各采一次完全无信息硬币并错误按样本结果分组时，样本内分类估值可为 75%，真实最优为 50%。这是随机教师的风险案例，不是当前旧版教师或模型分数已虚高 25 个百分点的实测结论。简化二状态的净 VoI +0.25/-0.15 也复算一致，不代表干预式工具可忽略世界转移。
